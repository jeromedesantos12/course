# Pokemon Catcher

Aplikasi ini adalah permainan sederhana untuk "menangkap" Pokemon.

## Alur Kerja Aplikasi

1.  **Tampilan Awal:** Saat halaman dimuat, aplikasi akan menampilkan 500 gambar Pokemon beserta nomornya.
2.  **Interaksi Pengguna:** Pengguna dapat mengklik gambar Pokemon mana saja. Setiap gambar yang diklik akan ditandai sebagai "tertangkap" dengan perubahan gaya (lingkaran berwarna).
3.  **Kondisi Kemenangan:** Setelah semua 500 Pokemon berhasil ditandai (diklik), sebuah pesan "SELAMAT!!" akan muncul, menandakan bahwa pengguna telah berhasil menangkap semua Pokemon.
